# TriMed
## Overview
### Description
![Full Container](Assets/full.png)
*Image of the full, capped container*

A simple 3D-printed medicine holder to store three different medications. Perfect for carrying basic over-the-counter medications or organizing medications for daily use.

**Printables:** [https://www.printables.com/model/1896940-trimed-a-three-compartment-medication-container](https://www.printables.com/model/1896940-trimed-a-three-compartment-medication-container)
### Features
![Uncapped container](Assets/uncapped.png)

*Image of the uncapped container, exposing the internal divider*
* Three separate compartments to organize medications
* A rotating internal divider that snaps to expose one medication at a time
* 3D-printed screw-on lid.

### Why?
I designed this for my own personal use to carry over-the-counter medicine.

### **Important Note**
**This IS NOT a medically approved or tested container. It is not child-proof, moisture-proof, or guaranteed to safely store medication. This is not intended to replace original medication packaging in any way.**

## Guide
### Materials
* **PLA** or any other rigid filament
### Printing
**Body**
* Print with the **circular base on the bottom**. The cavity should be facing up.

**Lid**
* Print with the **flat circular section adhered to the bed**.

**Divider**
* Print the divider with the **flat part facing down**. The cylindrical protrusion should face upwards.

### Assembly
1. **Insert the divider into the body.** Ensure the cylinder fits into the corresponding hole in the body and that the bumps latch into the grooves inside the body.
2. **Screw on the lid**
